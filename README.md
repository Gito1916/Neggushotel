# NeggusHotel

NeggusHotel is a simple static HTML website for a hotel. This repository contains the site's HTML, assets, and styles for presenting rooms, amenities, and contact information.

## Preview
Open `index.html` in your browser to view the site locally.

## Features
- Responsive HTML layout for a hotel landing page
- Sections for rooms, amenities, booking/contact information
- Static assets (CSS, images) organized under appropriate folders

## Repository structure
- index.html — main entry page
- /css — stylesheets
- /images — site images and assets
- /js — optional JavaScript (if present)

(Adjust the structure above if your repo uses different folders.)

## Local development
1. Clone the repository:
   git clone https://github.com/Gito1916/Neggushotel.git
2. Open `index.html` in a web browser.
3. Or serve locally with a simple HTTP server:
   - Python 3: `python -m http.server 8000`
   - Node (http-server): `npx http-server .`

## Deployment
You can host this site using GitHub Pages:
1. In the repo settings, enable Pages and choose the branch containing `index.html` (often `main` or `master`).
2. The site will be available at `https://<your-username>.github.io/Neggushotel/` after publishing.
